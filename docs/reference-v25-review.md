# V25 候选规则与上线边界（2026-09-07）

本分支是独立候选版，不是线上渲染版本。原工作目录的 Mac 定时任务及 GitHub Pages 图片没有切换至此版本。

## 已完成的渲染改动

- 手机用 1320×2868 原生分辨率计算，不再先缩至 68% 再放大；Mac 保持 2560×1664。
- 静态底图、灯光、地形使用 8K 图源。加入 NASA MODIS 水体掩膜，避免依赖海水颜色判断陆地。
- 海洋从深蓝向较明亮的蓝色过渡；陆地适量暖化；减少灰色加法补光，保留夜晚材质色相。
- 云与地表共用球面坐标，不变形实际云系；减轻掠射边缘的硬切割。
- 按卫星观测时刻选用可见光/红外素材，按独立的当前时刻计算太阳位置。
- 根据 NASA 的增强红外色表恢复连续温度顺序，再投影与着色，不再把色彩饱和度直接当云层厚度。
- 夜间云层的透明度不随日落凭空提高；城市光只来自地表，在云下面合成。
- 城市灯光保留原始亮点、白色核心与暖色外围，不再压成单一金色色块。
- 使用较新的 WMTS 观测索引，避免 WMS 目录缓存落后造成额外延迟。

## 真实性限制

云层位置来自实际观测，但单通道红外不能唯一确定真实云高、光学厚度或所有低云。增强色表还存在极冷灰阶与暖灰阶的歧义；本版采取保守解码，不声称科学级云厚度重建。夜间可读性补光是展示用的调色，不代表真实照度。城市灯光仍为 VIIRS 2012 静态观测基底，不代表此刻每栋建筑开关灯状态。

## 定位状态
