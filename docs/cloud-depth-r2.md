# 云层厚度修订（2026-09-07）

在用户认可 V25 的其他变化后，本次只调整云材质与云的合成，不修改海陆调色、地表、相机、太阳、大气参数和城市光源。用户已于 2026-09-07 确认上线；发布状态与验证记录见 `cloud-depth-r2-release.md`。

- 中厚云增大光学遮挡，密集云体的最大不透明度由 0.94 增至 0.975；薄云不做统一加厚。
- 三个尺度的卫星纹理提供云顶、内部层次与柔和凹处阴影。不添加随机云纹理，不移动云系，也不扩张云的覆盖范围。
- 白天坡面明暗跟随太阳方向；夜间只保留局部层次与展示用环境补光，不伪造太阳照射方向，不反射地表城市灯光至云顶。
- 掠射角逐渐减弱微小起伏，避免球体边缘出现浮雕、错位或第二条轮廓。
- 云外像素保持原样。城市灯光在加厚的云下面被更强地遮挡。

这是二维观测驱动的视觉厚度，不是实测三维云高。单通道增强红外本身的温度歧义和低云识别限制仍在，不能靠渲染重建缺失的观测细节。

验证：75 项测试通过，涵盖云外像素不变、厚薄云遮挡区别、无夜间假太阳方向、灯光始终在云下。上线前仅增加内存优化：按实际采样像素解码红外色表、及时释放不再使用的材质数组。四张成品与确认版逐像素一致。2 GB 服务器在 1450 MB 进程内存限制下完成两张手机图，耗时约 41 秒。
